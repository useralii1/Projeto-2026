# Meu Dinheiro Fácil
### Sistema de Controle de Gastos Pessoais

O **Meu Dinheiro Fácil** é um projeto desenvolvido com a proposta de tornar a organização financeira mais simples e acessível.

A ideia é ajudar as pessoas a entender melhor como estão utilizando seu dinheiro, permitindo registrar receitas, acompanhar despesas e visualizar o saldo disponível.

Com uma interface simples e intuitiva, o sistema busca incentivar hábitos financeiros mais conscientes, facilitando o planejamento e ajudando os usuários a terem mais controle sobre suas finanças no dia a dia.

## Objetivo do Projeto

Desenvolver uma aplicação web que facilite o controle das finanças pessoais, permitindo que os usuários organizem suas movimentações financeiras, acompanhem seus gastos e tenham uma visão mais clara do próprio orçamento.

## Funcionalidades

O sistema contará com as seguintes funcionalidades:

- **Controle financeiro:** acompanhamento das receitas e despesas.
- **Cadastro de receitas:** registro dos valores recebidos.
- **Cadastro de despesas:** registro dos gastos realizados.
- **Organização financeira:** visualização das movimentações por período.
- **Saldo disponível:** cálculo automático da diferença entre receitas e despesas.
- **Planejamento financeiro:** identificação dos principais gastos e oportunidades de economia.

> **Observação:** as funcionalidades apresentadas fazem parte da proposta inicial do projeto e poderão ser ajustadas conforme o desenvolvimento da aplicação.

## Tecnologias Utilizadas

O projeto será desenvolvido utilizando tecnologias fundamentais para o desenvolvimento web:

- **HTML5:** responsável pela estrutura e organização das páginas.
- **CSS3:** utilizado para a aparência, estilização e responsividade do sistema.
- **JavaScript:** responsável pela lógica, funcionalidades e interatividade da aplicação.
